# 围堵小猫

原创、无第三方依赖的本地浏览器游戏。支持同屏双人、人类对 AI、AI 对 AI，以及可保存和导入的不规则地图。当前版本的双人是同一台设备轮流操作，不包含跨设备联网房间。

## 开始游戏

双击本目录的 **开始游戏.html**，或打开 `dist/index.html`。不需要安装依赖或连接互联网。

也可以在本目录运行 `npm start`，然后访问 http://127.0.0.1:4178 。本地服务只监听当前电脑，不开放到局域网。两种入口的浏览器存储彼此独立；跨入口搬运地图请使用 JSON 导出和导入。

## 玩法

- 围堵方先手，在任意空地放置一个永久障碍，不能覆盖小猫或已有障碍。
- 随后小猫走到六个相邻地块之一，不可跳跃、穿墙或原地停留。
- 小猫走到绿色外圈标记的出口，猫方立即获胜。
- 围堵方切断猫到所有出口的通路，立即获胜，不必将猫的六个邻格全部封住。
- 出口本身可以被封堵；棋盘之外和内部空洞都不可走。
- 默认双方由人类控制。右侧可以独立将猫或围堵方切换为 AI，双方均选 AI 可以观战。
- 暂停仅暂停自动 AI 行动，人类回合仍可操作。“AI 走一步”可替任意当前方走一步，并保持暂停。
- 悔棋后暂停 AI。人机对弈尽量回到人类上一次行动之前；同屏双人或双 AI 对局回退一次行动。

## 地图与随机障碍

内置缺角岛屿、月牙湾、环形庭院、随机岛屿、六角原野。默认半径 10，约 250～330 格（缺角岛屿为 321 格）；还可以选择半径 8 或 12。预设猫起点优先放在离出口最远的内部位置，凹口只削去外围地块，避免出口深入猫的附近。

障碍比例控制新增随机障碍数量，不包含固定障碍，默认为 **35%**。默认开启“围堵挑战 · 筛选有解对局”：先随机散布障碍，再筛选至少四条独立出路、至少四个可走邻格、足够逃生纵深且已有围堵必胜证明的开局。**不补造包围线，不增加指定的障碍数量。**相同地图、障碍比例、模式和种子会复现开局。

筛选在后台进行，显示尝试进度，可取消。没有找到合适开局时保留当前棋盘，不把未知局面标成有解；可以换种子或关闭筛选。自由模式只保证保留逃生路径，不保证哪一方必胜。旧包围线构造器不再用于游戏开局。

研究中的分支证明搜索已接入游戏。认真和深思 AI 能根据猫的选择沿不同策略分支应对；轻快围堵 AI 只在附近试探追堵，保留失误空间。双人可以点“换边重玩”，沿用同一开局交换角色；小猫挑战建议选轻快 AI 或关闭有解筛选。筛选模式面向围堵解谜，不承诺双方五五开。

## 可解性

右侧分别显示本局开局结论和当前局面结论：**已证明围堵方可胜 / 已证明小猫可逃 / 尚未证实**。本项目将“围堵方有解”定义为：在围堵方先手且双方遵守规则的前提下，围堵方存在针对猫所有合法选择都能获胜的策略。它不只是猫能否走到出口，也不是两套 AI 对打一局的结果。

手动点击“验证当前局面”会暂停自动 AI。后台使用混合证明数搜索，导出并核验分支策略；固定方案作为证明捷径保留。完整搜索可能超时，此时显示“尚未证实”；如果当前局面已有有效证书，不会因为重算超时而丢掉结论。悔棋和重玩会恢复对应的策略证书。详见 `可解性说明.md`。

在“自定义”里选择工具后点击或拖动：

- **地块 / 擦除**：改变地图形状。
- **猫起点**：指定初始位置，不能在出口或固定障碍上。
- **出入口**：手动增删出口；首次使用会从自动出口切换为手动模式。
- **固定障碍**：增删每局保持的障碍；新局还会在其他地块上随机加障碍。

自动出口使用地图外部的空白区域判定：与外部空白相邻的地块为出口，封闭的内部空洞不产生出口。手动模式允许自行指定出口，包括内部地块。

地图需要 7～625 个地块，坐标范围为 -16～16。所有地块必须连通，必须存在出口且猫能到达出口。编辑器允许暂时画出不合法草稿，但应用、保存、导出时会检查。取消编辑会保留原对局。自定义形状保持实际格数，不受预设大小选项影响。

“保存到本机”保存一张地图到当前浏览器；导出 JSON 可以长期备份或发给另一台电脑。不会上传地图。

## 两个 AI

双方分别控制自己的行动，使用同一个对抗搜索引擎和正式规则。详见 `AI说明.md`。

## 文件

- `dist/rules.js`：六方向拓扑、地图验证、外轮廓出口、随机开局与胜负判定。
- `dist/ai.js`：猫方和围堵方的行动搜索。
- `dist/tactics.js`：紧凑局面上的有限预算对抗搜索。
- `dist/proof.js`：分支证明、独立检查、策略跟随和抵抗路线。
- `dist/openings.js`：普通随机开局的质量筛选，不构造围墙。
- `dist/solver.js`：策略证书、全猫路径核验、可解开局生成与三值求解器。
- `dist/app.js`：对局、编辑器、悔棋、AI 任务取消、存取地图。
- `dist/index.html` / `dist/style.css`：界面。
- `tests/`：规则、AI 对战、控制器状态和静态资源检查。

运行 `npm test` 执行测试，不需要安装 npm 包。测试覆盖规则和控制器逻辑，不代替真实浏览器视觉或操作手感验收。

本次更新的验证结果见 [更新与可玩性验证](更新与可玩性验证.md)。此前论文阅读与原型基线保存在 [研究报告](research/研究报告.md)，其中“未接入”的描述属于更新前的研究记录。
